# How to Build the Best Agent Team — living synthesis

`curator` revises this page whenever a new cycle materially changes the picture. It is the one-page answer the-owl is continuously refining about its own craft.

## Current thesis (seed — pre-research)
the-owl's own architecture encodes the current best-practice baseline, which future cycles will test and extend:
- **Hub-and-spoke over mesh** — an orchestrator delegates; specialists hand off, never call each other.
- **Context-minimal handoffs** — pass N-1 output + pointers, not full history.
- **Role hard-stops + mandatory delegation** — each agent stays in its lane.
- **Every change is an ADR** — traceable, reversible evolution.
- **Markdown-only, no runtime** — the team is prompts + conventions + a schedule.

## Open fronts (what cycles should pressure-test)
- Handoff **contract** formats between agents.
- Memory/context strategies beyond N-1 scoping.
- Self-improvement/eval loops (this project is itself one — dogfood it).
- Guardrail patterns for autonomous self-modification.
